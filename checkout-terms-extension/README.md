# ŚEORA – אישור תקנון בדף התשלום (Checkout UI Extension)

דף התשלום של Shopify נעול לעריכה מתוך ה-theme. הדרך היחידה להוסיף בו תיבת סימון
היא **Checkout UI Extension** שמותקנת דרך אפליקציה מותאמת (Custom app) של החנות.
התיקייה `extensions/terms-consent` מכילה את ההרחבה המוכנה. מה שנשאר הוא לפרוס אותה
פעם אחת מהמחשב שלך (נדרשת התחברות ל-Shopify בדפדפן, לכן זה לא יכול לרוץ מכאן).

## מה ההרחבה עושה
- מציגה תיבת סימון "קראתי ואני מאשר/ת את תקנון האתר ואת מדיניות הפרטיות" עם קישורים.
- חוסמת לחיצה על "שלם עכשיו" / מעבר בין שלבי התשלום עד שהתיבה מסומנת, ומציגה הודעת שגיאה.
- שומרת את האישור על ההזמנה כ-cart attribute בשם `אישור תקנון` = `כן` (נראה בפרטי ההזמנה באדמין).
- כל הטקסטים והקישורים ניתנים לעריכה מתוך עורך דף התשלום (Settings → Checkout → Customize).

## התקנה (פעם אחת, כ-10 דקות)

דרישות: Node.js 20+ ו-npm על המחשב.

```bash
# 1. יצירת אפליקציה חדשה (בוחרים: "Build an extension-only app")
npm init @shopify/app@latest -- --name seora-checkout-terms
cd seora-checkout-terms

# 2. העתקת ההרחבה מהריפו לתוך האפליקציה
cp -r <path-to-repo>/checkout-terms-extension/extensions/terms-consent extensions/

# 3. התקנת תלויות
npm install

# 4. בדיקה בזמן אמת בחנות (פותח דפדפן, מתחברים לחשבון Shopify ובוחרים את החנות ŚEORA)
npm run dev

# 5. פריסה לחנות
npm run deploy
```

לאחר ה-deploy:
1. באדמין: **Settings → Apps and sales channels** – ודאו שהאפליקציה `seora-checkout-terms` מותקנת בחנות.
2. **Settings → Checkout → Customize** (עורך דף התשלום).
3. בצד שמאל לוחצים **Add app block**, בוחרים **ŚEORA – אישור תקנון**, וגוררים את הבלוק
   למקום הרצוי. מומלץ: מתחת לאמצעי התשלום, ממש מעל כפתור "שלם עכשיו".
4. לוחצים על הבלוק כדי לערוך טקסטים וקישורים, ואז **Save**.

ההגדרות חלות על כל דפי התשלום בחנות (כולל Shop Pay ותשלומים מהירים), בכל המכשירים.

## גיבוי בתבנית (כבר פעיל)
בנוסף, התבנית עצמה כוללת את אותה תיבת אישור בעגלה (מגירת העגלה ודף העגלה),
דרך ה-snippet `snippets/seora-terms-consent.liquid`. היא חוסמת את כפתור "לתשלום"
עד לאישור, ושומרת את אותו attribute על ההזמנה.
