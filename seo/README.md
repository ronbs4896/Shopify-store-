# SEORA (seora.co.il): בלוג ו-SEO

הבלוג וה-SEO של החנות SEORA ב-Shopify: המאמרים, הכלי שבונה אותם, מדריך החיבור ל-GA4 ול-Search Console וממצאים לטיפול.
התיקייה לא עולה לתבנית. התבנית מתעדכנת רק מהקבצים שב-`sections`, `snippets` ו-`templates`.

## מה יש כאן

| קובץ | מה בו |
|---|---|
| `blog/articles.json` | חמשת המאמרים: כתובת, כותרת, כותרת SEO, תיאור מטא, תקציר, תגיות ותמונה ראשית |
| `blog/src/*.html` | המאמרים עם סימונים לקישורים ולכרטיסי מוצר |
| `blog/build.py` | בונה את המאמרים, בודק שכל קישור מוביל למוצר, לקטגוריה או למאמר קיים, ומתריע על מוצר שאזל מהמלאי |
| `blog/out/` | ה-HTML הסופי שעולה ל-Shopify, ו-`manifest.json` |
| `blog/data/products.json` | המוצרים שמהם נבנו הכרטיסים: שם, מחיר, האם במלאי ותמונה (אוקטובר 2026). בלי כמויות מלאי, כי הריפו ציבורי |

בנייה מחדש אחרי שינוי: `python3 seo/blog/build.py`. הבנייה נכשלת אם יש קישור שבור.

## GA4: חיבור (5 דקות, רק בחשבון Google של רון)

1. בשופיפיי: Apps, מחפשים **Google & YouTube** (האפליקציה הרשמית של Google, חינמית) ומתקינים.
2. מחברים את חשבון Google שבו רוצים את הנתונים.
3. בהגדרות האפליקציה, תחת Google Analytics: מחברים property קיים של GA4, או יוצרים חדש בשם SEORA.
4. זהו. האפליקציה מעבירה גם אירועי מסחר: צפייה במוצר, הוספה לסל, התחלת תשלום ורכישה.
5. בדיקה: ב-GA4 נכנסים ל-Reports ואז ל-Realtime, פותחים את האתר מהטלפון ורואים את עצמכם.

לא מוסיפים בנוסף קוד GA ידני לתבנית, כדי שהביקורים לא ייספרו פעמיים.

## Google Search Console: חיבור (10 דקות)

1. נכנסים ל-search.google.com/search-console ובוחרים Add property.
2. בוחרים **Domain** וכותבים `seora.co.il`. גוגל נותן רשומת TXT.
3. מוסיפים את רשומת ה-TXT איפה שמנוהל ה-DNS של הדומיין:
   - אם הדומיין נקנה דרך שופיפיי: Settings, Domains, seora.co.il, DNS settings, Add custom record, סוג TXT, Name `@`, ובערך המחרוזת מגוגל.
   - אם הדומיין אצל רשם אחר: בממשק ה-DNS שלו, באותה צורה.
4. חוזרים ל-Search Console ולוחצים Verify. לפעמים לוקח מכמה דקות עד כמה שעות.
5. אחרי האימות: Sitemaps, מקלידים `sitemap.xml` ולוחצים Submit.
6. URL Inspection: מדביקים את כתובת הבלוג ואת חמשת המאמרים, ולוחצים Request indexing לכל אחד.
7. ב-GA4: Admin, Product links, Search Console links, ומחברים את שני הכלים.

חלופה בלי DNS: property מסוג URL prefix עם `https://www.seora.co.il`, שיטת HTML tag, ומדביקים את שורת ה-meta
בתבנית: Online Store, Themes, שלוש נקודות, Edit code, `layout/theme.liquid`, מיד אחרי `<head>`. את התבנית החיה
אי אפשר לערוך מכאן (שופיפיי חוסם כתיבה לתבנית הפעילה דרך ה-API), ולכן את השורה הזאת מדביקים בעורך של שופיפיי.

## תיקונים קטנים בתבנית (2 דקות, בעורך העיצוב)

1. Online Store, Themes, Customize. בתפריט העליון בוחרים Blogs ואז Default blog.

## ממצאי SEO נוספים (לא טופלו, מחכים להחלטה)

1. **אין תיאור מטא לדף הבית.** הצעה, ב-Online Store, Preferences:
   כותרת `SEORA | תכשיטי מואסנייט ושעוני מותגים`,
   תיאור `תכשיטי מואסנייט מכסף 925 עם תעודת GRA ואחריות לשנה, ושעוני מותגים עם אחריות לשנתיים. משלוח עד 5 ימי עסקים ואריזת מתנה בכל הזמנה.`
2. **לאף קטגוריה אין טקסט או תיאור מטא** (19 קטגוריות). פסקת פתיחה של 80 עד 150 מילה ותיאור מטא לקטגוריות המרכזיות הם השיפור הבא בגודלו.
3. **בתפריט הראשי, "שעונים לגברים" מוביל ל-`/collections`** (רשימת כל הקטגוריות) ולא לקטגוריית שעונים לגברים.
4. **אין קטגוריה אחת לכל השעונים לנשים.** אפשר ליצור קטגוריה חכמה לפי התגית הקיימת "שעוני נשים".
5. **שני כתיבים**: "מוסאנייט" ו"מואסנייט" בשמות הקטגוריות. כדאי לבחור כתיב ראשי אחד ולהזכיר את השני בטקסט.
6. **תיאורי מוצרים**: שורה אחת של מפרט, עם טעויות שחוזרות ("חומר הצמיד" בעגילים ובשרשראות, "ציפוי סודיום" או "פודיום" במקום רודיום, "HOGO BOSS").
   ובטבעת המרקיזה, השם אומר SR1084 והכתובת אומרת sr1184. המאמר על טבעות אירוסין משתמש בשם שמופיע בחנות (SR1084).
